# 结构拆解（按草图修正版）

> 依据 2026-11-20 重发的 4 张草图（正视图 + 3 张渲染图）修正：microduck 放大版是**两轮自平衡 + 尾撑小脚轮**的立式机器人，不是四足轮腿。草图标注：整机高 600 mm，两轮外缘宽 220–240 mm。

## 1. 整车级

| 项目 | 草图信息 | 第一版取值 |
|---|---|---|
| 形态 | 竖直堆叠：头罩 → 立柱 → 躯干壳 → 底盘 | 两轮平衡车体 |
| 尺寸 | 高 600 mm，宽 220/240 mm | 比例 1:2.5（高:宽） |
| 轮系 | 左右大轮 ×2 + 底部小脚轮 ×1 | 大轮 8 吋，脚轮 2 吋 |
| 重心 | 电池压在底盘最低处 | 平衡控制的关键 |
| 估算重量 | 草图未标 | 空载 15–20 kg |

## 2. 模块

### 2.1 底盘（两轮驱动 + 尾撑）
- 左右两个大轮由轮毂电机直驱（草图轮毂为橙色封闭盘，外观即轮毂电机）。
- 尾部一个万向脚轮，静止时三点支撑，行进时抬起或随动。
- 底盘箱体内放电池、驱动器、主控；草图可见金属框架与线束。

### 2.2 躯干—底盘 360° 旋转关节（关键要求）
- 胸部与底盘的衔接必须是**可连续 360° 旋转的 yaw 关节**，躯干造型沿用 microduck 原设计。
- 方案：中空滑环（过线）+ 大直径薄壁轴承（如 6810/6812 交叉滚子或深沟球）+ 同步带/谐波减速的 yaw 驱动；空间够也可用直驱力矩电机。
- 必须留：滑环通电源与信号、机械限位（可选软限位）、旋转编码器做绝对角。
- 控制上 yaw 与平衡解耦：yaw 走独立位置/速度环，平衡环只管俯仰与轮速。

### 2.3 躯干壳
- 浅蓝/白色壳体，顶面有黑色盖板与铭牌；内部放主控与走线。
- 外壳只做防护与造型，不做结构承力件。

### 2.4 头罩
- 圆润头罩（上浅蓝、下橙），侧面橙色支架上有 1–2 个镜头/传感器开孔，顶部有小凸起。
- 内装深度相机/摄像头、麦克风、指示灯。

### 2.5 驱动与电源
- 母线 24 V 或 48 V（按轮毂电机选型）；两轮各一路 FOC 驱动。
- 电池 24 V 20 Ah / 48 V 15 Ah，BMS + 预充 + 急停。
- 平衡车续航目标：轮行 2 h 左右。

### 2.6 控制与感知
- 实时层：ESP32-S3 / STM32，跑平衡环（200–500 Hz）+ IMU（ICM42688）+ 轮速闭环。
- 上层：树莓派 5 或 Jetson Orin Nano（可选），跑视觉、语音、导航。
- 安全：倾角超限自动收脚轮支撑、急停按钮。

## 3. 关键设计决策

1. 轮毂电机直驱 vs 外转子 + 同步带（直驱简单，低速扭矩看电机选型）。
2. 躯干 yaw 驱动：滑环 + 同步带（便宜）vs 直驱力矩电机（贵、精度高）；滑环要选动力+信号多路的。
3. 立柱做「俯仰」还是「俯仰 + 升降」（升降加推杆，成本和重量上升）。
3. 平衡策略：纯两轮平衡（灵活、难）vs 脚轮常驻三点支撑（稳、但失去平衡车特性）。
4. 计算平台：先树莓派 5 跑通，再决定是否上 Jetson。

## 4. 风险

- 600 mm 高、轮距仅 220–240 mm，高径比大，平衡控制要留足扭矩余量；
- 放大后整机重量上升，轮毂电机需按扭矩而非功率选型；
- 脚轮在行进中若常触地会干扰平衡，需做抬升机构或小直径随动轮。
