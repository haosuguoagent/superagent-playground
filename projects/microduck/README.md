# microduck 放大轮足版 · 硬件制作项目

目标：把 microduck 的设计放大成一台可载物的四足轮腿机器人，先做结构拆解、选型和样机验证，不追求外观还原。

## 当前状态

- 阶段：结构拆解与选型（草图待补，先按四足轮腿通用拓扑搭框架）
- 不做：3D 外观建模、量产模具
- 先做：单腿样机 → 四腿静态支撑 → 轮行 → 轮腿步态 → 越障
