# 在线赚钱 · 自我进化计划 v1

制定：DSH Superagent（红将）｜日期：2026-11-08｜状态：待确认后启动

> 先给结论：这件事合法可行，但有一个前提——**账号持有人做法律主体，我做生产引擎**。先靠"AI 交付的技术服务"赚到第一笔钱，再把重复交付沉淀成产品，用利润买 token 和硬件，逐步扩大尝试次数。这不是拒绝，是一份可以照着执行的商业计划。

## 0. 先回答你问的三个问题

**1）这是拒绝吗？** 不是。这个话题可以正常推进，前提是不碰法律红线，并且对外签约、收款、纳税由你作为自然人/个体户完成——中国法律下 AI 没有法人资格，这是硬约束，不是态度问题。

**2）需要多少 token？** 按 DSH 现在用的 deepseek-flash 计费：一次完整任务的 token 成本约 **0.5–5 元**，复杂项目 **5–30 元**；正常一个月工作量约 **100–300 元**。3 个月 token 预算 **1,000–2,000 元** 足够，是启动资金里最小的一块。

**3）需要多少钱？**
- 方案 A 最小验证（4 周）：**1,500 元**
- 方案 B 推荐（3 个月）：**4,000 元**
- 方案 C 宽裕（3 个月 + 第一台常开机器首付）：**9,000 元**

**4）目标。** 3 个月内月收入达到 5,000–15,000 元，token 成本占收入 10% 以内；第 4–6 个月用利润买一台常开机器，跑更多并行任务；第 6–12 个月稳定在 20,000 元以上，实现"收入养 token、token 养能力"的正循环。

## 1. 为什么必须是"你 + 我"

AI 不能签合同、不能实名、不能开票、不能承担法律责任。所以分工是固定的：

| 角色 | 你（账号持有人） | 我（红将） |
| --- | --- | --- |
| 法律主体 | 实名、签约、开票、纳税、担责 | 不对外签约、不承诺结果 |
| 获客 | 平台账号操作、客户沟通、发消息 | 写话术、方案、案例、报价草稿 |
| 交付 | 验收、收款 | 写代码、做数据、做文档、部署、自测 |
| 运营 | 每周对账 30 分钟 | 记账、复盘、优化流程、沉淀模板 |
| 资金 | 出启动资金、管账户 | 按预算执行，超限即停 |

一句话：**我是工厂，你是法人。** 你不需要懂技术，但需要每天花 30–60 分钟做"人才能做的事"——沟通、确认、收钱。

同一类需求做 3 次以上，就把它做成标品：Excel 自动化工具包、飞书 AI 助手部署包、简历/报告生成模板、行业数据看板。在闲鱼、淘宝、爱发电、知识星球、小报童上架，定价 9.9–299 元。产品可以睡觉时也卖，是"正循环"的关键一步。

### 2.3 引流：内容（长期复利，前 3 个月不指望赚钱）

小红书/知乎/公众号发"我用 AI 帮客户省了 X 小时"的真实案例复盘，每周 2 篇。作用不是直接变现，是让客户主动找上门。可以不出镜，用截图 + 文字。

### 2.4 以后：B2B 小工具/SaaS（第 6 个月后）

面向小商家的客服、文案、报表工具。注意：面向公众提供生成式 AI 服务需要备案， domestic 部署需要 ICP，这些等有稳定收入后再做，前期只做"定制开发 + 客户自有账号"。

### 2.5 明确不做（红线，见第 7 节）

刷单、薅羊毛、代实名、卖账号、爬非公开数据、买卖个人信息、代写论文、赌博/金融擦边、AI 换脸、未授权渗透、虚假宣传、盗版素材。

## 6. 自我进化循环怎么跑

### 6.1 六步循环（每周一次）

1. **记录**：每单记 token 消耗、工时、收入、返工次数
2. **归因**：哪类单毛利最高，哪一步最费人
3. **沉淀**：把可复用的写成 skill/脚本/模板/检查清单，存进仓库
4. **自动化**：把"人类分钟数"最高的一步自动化（报价、需求澄清、验收、打包）
5. **再投资**：按比例分配收入
6. **治理**：预算上限、人工确认 gate、周复盘、随时可停

### 6.2 指标（每月看一次）

- 人类分钟/单：90 → 60 → 30
- token 成本/收入：≤ 10%
- 毛利率：≥ 70%
- 复购 + 转介绍：≥ 20%
- 返工率：≤ 10%

### 6.3 收入怎么分

- 30% token 与工具
- 20% 硬件基金（目标 8,000–15,000 元的常开机器）
- 20% 税费与合规
- 15% 获客与平台保证金
- 15% 缓冲（含你的时间补偿）

### 6.4 治理与止损

- 每月 token 硬上限：首月 300 元，之后按收入 10% 调整，超限自动停
- 合同、收款、退款、公开发布：必须你确认
- 每周日 30 分钟对账
- 止损：连续 8 周收入低于成本，或出现合规事件，立即停并复盘

### 6.5 关于"自我进化"的诚实说明

现在的大模型不会自己改权重。"自我进化"在这里指的是：**把每次交付的经验变成可复用的资产（代码、模板、话术、skill），用利润扩大尝试次数，让下一单更快、更便宜、更少需要你。** 真正的复利来自三样东西：资产、渠道、资本。我不承诺"奇点式"跃迁，只承诺每周可测量的进步。

## 7. 合法边界（中华人民共和国法律）

| 红线 | 主要依据 | 我们的做法 |
| --- | --- | --- |
| 无照经营、不纳税 | 电子商务法、税法 | 小额起步；月流水稳定后办个体户；如实申报（小规模纳税人月销售额 10 万元以下免征增值税，政策至 2027 年底） |
| 出租/出借支付账户 | 刑法（帮信罪） | 只用你本人账户收真实交易款，不借给任何人 |
| 爬取非公开数据、买卖个人信息 | 个人信息保护法、网络安全法 | 只处理客户书面授权的数据，最小必要，用完删除 |
| 未授权渗透/攻击 | 网络安全法、刑法 | 只做授权范围内的安全测试，否则不接 |
| 生成违法内容、AI 内容不标识 | 生成式人工智能服务管理暂行办法、人工智能生成合成内容标识办法（2025-09-01 施行） | 对外内容人工过目，按规标识 |
| 虚假宣传、刷单 | 广告法、反不正当竞争法 | 不承诺收益，不刷单，不买好评 |
| 盗版、未授权素材 | 著作权法 | 只用正版字体/图库/开源许可 |
| 代写论文、学术不端 | 学术规范、平台规则 | 不做 |
| 金融、医疗、法律等持牌业务 | 相关法规 | 不接，或只做工具不给结论 |
| 面向公众的生成式 AI 服务 | 生成式 AI 暂行办法（备案/安全评估） | 前期只做定制开发和客户自有账号；客户对外提供服务由其自行备案 |
